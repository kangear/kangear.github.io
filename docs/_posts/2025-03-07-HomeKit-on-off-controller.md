# 开始之前

有朋友咨询`HomeKit通断器`可否根据根据电量为iPad充电，也就是电量低于10%开始充电，充电到90%则停止充电，这种需要是可以实现的，需要借助`快捷指令`。

这样就实现了`iPad电量低于10%时自动充电，高于90%时自动停止充电`，以上操作需要在iPad上进行，教程上只是在iPhone上进行演示。
