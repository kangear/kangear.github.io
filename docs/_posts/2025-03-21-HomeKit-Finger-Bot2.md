# 5. 充电

如果力不够说明电量不足需要充电；该设备不支持快充，需要使用USB-A口转C口线插到USB伴侣尾部进行充电，如果指示灯不显示，可以按下指示灯旁边的按键。

## 5.1 指示灯说明

```
闪烁：充电中
常亮：已充满
```
