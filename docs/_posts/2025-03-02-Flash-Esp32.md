## 升级

| ![](/assets/微信截图_20250302101021.png) | 
| :------------: |
|        连接成功之后效果    | 

连接成功之后，需要做如下修改配置
1. 删除下面三行，只保留第一行，方法为点击右侧(X)

| ![](/assets/微信图片编辑_20250626162146.jpg) | 
| :------------: |
|        删除下面三行    | 

2. 0x下面改为0，然后点击SELECT选择固件
3. 点击`EARSE`进入擦除（图略）
4. 点击`PROGRAM`进行升级

| ![](/assets/微信截图_20250302101121.png) |
| :------------: | 
|        点击`PROGRAM`进行升级    |

| :------------: | :------------: | 
|   弹窗点击`CONTINUE`继续     |        软件升级过程   |
