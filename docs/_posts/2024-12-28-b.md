# 使用控制

1. 可以通过`家庭App`控制   
触摸黄色图标直接开关；

2. 可以通过`Siri`控制   
`Siri 开灯`
`Siri 关灯`

3. 通过`控制中心`控制

# 恢复出厂

设备上的按钮`长按10秒钟`指示灯由闪烁到熄灭，即可恢复出厂。
